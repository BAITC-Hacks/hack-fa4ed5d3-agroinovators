Hackathon team repository for Agroinovators


## TaskAtlas AI

TaskAtlas AI is an agricultural workforce platform that connects
agricultural organizations with students, specialists, and student teams.

### Main features

- AI-assisted agricultural demand creation
- Agricultural Demand Readiness Score
- Interactive demand map
- Specialist and location filters
- Student/team applications
- Business application management
- Accept / Reject workflow
